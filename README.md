# 별이 빛나는 교실

중학교 「별과 우주」 수업용 웹사이트입니다. 학생들이 태블릿으로 별을 그려 보내면, 교사 노트북 화면의 고흐 「별이 빛나는 밤」 풍 은하에 바로 나타납니다. 두 번째 페이지 「지금의 우주」에서는 우주 팽창, 은하의 회전, 블랙홀, 중력 렌즈를 시뮬레이션으로 보여 줍니다.

학생은 계정이나 앱 설치 없이 웹 주소(또는 QR)로 들어옵니다.

## 수업에서 쓰는 순서

1. **교사 노트북**에서 사이트 주소를 엽니다. 「교사: 우리 반 은하」 화면에 **수업 코드 6자리**와 **학생 접속 QR**이 나타납니다.
2. 프로젝터에 QR을 띄웁니다. 학생은 태블릿 카메라로 QR을 찍으면 수업 코드가 채워진 그리기 화면이 열립니다.
3. 학생이 그림을 그리고 **은하로 보내기**를 누르면, 교사 화면 은하로 별이 날아 들어옵니다.
4. 「지금의 우주」 탭으로 넘어가 우주 이야기를 이어 갑니다.

주의할 점

- 수업 중에는 **교사 노트북의 은하 화면을 열어 두세요.** 그림은 교사 노트북 브라우저로 직접 전송되어 그 노트북에 저장됩니다. 화면을 닫으면 그동안 보낸 그림은 전송되지 않습니다.
- 받은 그림은 교사 노트북 브라우저에 최대 120장까지 저장되어 새로고침해도 남아 있습니다. 「모두 지우기」를 두 번 누르면 비워집니다.
- 새로고침해도 같은 수업 코드를 다시 쓰려고 시도합니다. 코드가 바뀌면 화면에 안내가 뜹니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소(public)를 만들고 이 폴더의 파일(`index.html`, `config.js`, `README.md`, `.nojekyll`)을 올립니다.
2. 저장소의 **Settings → Pages**에서 *Source*를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 두고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

## 학교 와이파이에서 전송이 안 될 때: Firebase로 바꾸기

기본 방식(PeerJS)은 기기끼리 직접 연결합니다. 일부 학교망은 이런 연결을 막습니다. 그럴 때는 무료 Firebase Realtime Database를 거쳐 보내도록 바꿀 수 있습니다.

1. <https://console.firebase.google.com> 에서 프로젝트를 만들고, **Realtime Database**를 만듭니다(위치: 싱가포르 `asia-southeast1` 권장).
2. 프로젝트 설정 → **웹 앱 추가** → 나오는 `firebaseConfig` 값을 `config.js`의 `firebase:` 자리에 붙여 넣습니다. `databaseURL`이 꼭 있어야 합니다.
3. Realtime Database → **규칙**을 아래처럼 바꿉니다(수업 방 경로만 열고, 그림 크기를 제한).

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        "drawings": {
          "$id": {
            ".write": true,
            ".validate": "newData.child('img').isString() && newData.child('img').val().length < 450000"
          }
        }
      }
    }
  }
}
```

이 규칙은 수업 코드를 아는 사람이면 누구나 그림을 보내고 지울 수 있는 수업용 설정입니다. 수업이 끝나면 데이터베이스의 `rooms`를 지우거나 규칙을 `false`로 바꿔 닫아 두세요.

## 파일

- `index.html`: 사이트 전체(학생 그리기, 교사 은하, 지금의 우주)
- `config.js`: 전송 방식 설정(기본은 설정 없음)
- 외부 라이브러리: PeerJS 1.5.4(전송), qrcodejs 1.0.0(QR), Google Fonts
